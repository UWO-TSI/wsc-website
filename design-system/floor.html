12  SponsorsTier bar in gold. Tile scale carries the hierarchy, not a border.
Partners
Northbound Kepler Alta Ridgeline Capital Vero Hale Stratton & Co

One tier group, because the sponsors table has no tier column and supabase/ is off limits. The bar and label are --gold, not --accent: a sponsor's standing has to read the same in both themes. Scale comes from display_order, the lead tile spanning two columns. The whole wall is --logo-ground, the third fixed mark, which does not flip with the theme. A sponsor's logo is supplied artwork we may not redraw and most of them are light-on-transparent, so on the Showroom ground they washed out. The ground is the panel, not a patch behind each mark: per-logo tiles read as a grid of stickers. Ink on it is --on-logo-ground, never --on-inverse, which flips. A sponsor with no file gets their name set in the display face in the same cell rather than a redrawn mark or an empty frame. A sponsor with a link is an anchor and scales slightly on hover; one without is inert.

13  SkeletonsA thing that has to load reserves its own space and fills in.

A skeleton is built to the shape of the thing it stands in for, not to a generic box. That is the whole point: a centred spinner has a different shape from the content that replaces it, so the page jumps the moment the query resolves. Here the row skeleton carries the same 30px index, name, meta and 34px avatar slot as a real ledger row, at the same rest padding, so the list occupies its final height from the first paint.

The fill is derived from currentColor, so one rule is correct on every slab tone without a variant per ground. Widths vary down a column, because identical bars read as a loading graphic rather than as names. The sweep is the one thing in the system that animates at rest, and it is deliberate: a static grey block reads as broken layout. It stops under reduced motion, and once the content behind it has loaded.

An image frame goes further: it holds its aspect ratio from the first paint, keeps the skeleton mounted behind the picture, and waits for the bytes before running Clip Reveal. Unmounting the skeleton on load leaves one frame where it is gone and the image is still clipped, which shows as a flash of empty.

This replaced three labelled bands, one per group, headed Presidents, Vice Presidents and Assistant Vice Presidents. Splitting people into titled tiers made the page about rank rather than about the team.

The order still carries the structure: presidents first, then vice presidents, then assistant vice presidents, read left to right. Each person's title sits under their name for anyone who wants it. Nothing announces the boundary between groups and no group gets a bigger cell.

Every cell is identical, and none of them is a card: no fill, no shadow, no border, no hover, no link. These are people, not controls. Headshots are always visible here, unlike on the event ledger, because a profile picture is the content rather than a flourish. A missing one falls back to initials on --sunken, which is a designed state and not a broken frame.

15  ExtendingWhat to do when the thing you need is not in here.
1Look first

Read this page before writing CSS. Most new components are an existing one re-composed.

2Spend tokens only

Every colour, radius, shadow, duration and easing comes from a token. No new hex, no new number.

3Reuse a sequence

Pick from the twelve named sequences. A thirteenth is a design decision, not an implementation detail.

4Add it back

Ship the component and its card on this page in the same change. If it is not here, it does not exist.

Do
  • Compose from Slab, Button, Eyebrow, Field, Row
  • Match the nearest component's padding and radius
  • Give it both themes and a focus ring
  • Name the sequence it uses
Do not
  • Invent a colour, a radius or a duration
  • Add a border to separate anything
  • Write a one-off animation
  • Ship it without a card on this page
